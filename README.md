One word an agent says when it has no idea what to do — **"Dunno"**.

The blunt admission "I don't know" from a machine that never admits it:
a genuine stall reaction, dry-funny on its own, instantly legible, and
fresh against the crowded Hallucinating / Recalculating / Buffering
entries already in the field. Built for
[make.fun's The Agent's Uh-Oh bounty](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4)
($2 in USDC, top 10 paid).

## Run it

```sh
node main.ts
```

This writes exactly `Dunno` plus a trailing newline (6 bytes) to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Deterministic,
no dependencies, no network.
